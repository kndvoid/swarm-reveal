Live demo

Every page can be rebuilt in front of you.

This demo page is loaded normally, then taken apart and drawn again by a swarm of AI cursors — text typed, panels traced, images swept in. Everything below stays clickable the whole time.

Get the code View on GitHub

Real DOM, not a copy

Elements are hidden and revealed in place, so clicks, forms and menus behave exactly as before.

Viewport first

What you can see is built before anything off-screen, so the page is never blank where you are looking.

Restores itself

Each element returns to its exact original state. A watchdog restores the page if anything fails.

One script tag

No dependencies, no build step, ~18 KB gzipped.

<script defer src="/dist/swarm-reveal.js"></script>

Measured, not claimed

59.7 fps average, p99 frame 16.9 ms, engine start 7–40 ms, zero console errors across a 391-page production scan.
